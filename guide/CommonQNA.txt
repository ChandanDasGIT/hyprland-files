1. to see all the pacman packages installed
    pacman -Qe
To print,
    pacman -Qe > installed-packages.txt

2. Search for a specific app: If you want to check if a specific package is in that list, use grep:
    pacman -Qe | grep hyprland

3. I want to find the location of a folder or file:
    find ~ -name "folder/file-name"

4. To update the system:
    sudo pacman -Syu

5. to install an app
    sudo pacman -S app-name

6. to uninstall an app
    sudo pacman -Rns package_name

7. how to know class of running windows
    hyprctl clients | grep -E "Window|class:"

8. how to know if i am using ufw or firewalld
    systemctl is-active ufw firewalld iptables nftables

    How to Read the Output
        ufw shows active: You are using UFW.
        firewalld shows active: You are using Firewalld.
        All show inactive or unknown: You do not have an active application firewall service running (or you are using raw nftables / iptables).

9. how to print history of kitty
    history > history.txt
