So, this is how you install wine in arch

1. sudo nano /etc/pacman.conf
2. remove the hashtag of 
    [multilib]
    Include = /etc/pacman.d/mirrorlist
3. Save and exit the editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).
4. sudo pacman -Syu
5. sudo pacman -S wine
6. sudo pacman -S wine-gecko wine-mono lib32-alsa-plugins lib32-gnutls lib32-mpg123
7. winecfg

next How to mount the office7 iso (keep it in desktop)
    1. sudo mkdir -p /mnt/msoffice (create a folder)
    2. sudo mount -o loop ~/Desktop/MSOffice7.iso /mnt/msoffice (this will mount)
    3. cd /mnt/msoffice ls -l (navigate to setup file)
    4. wine /mnt/msoffice/SETUP.EXE (run the installer)
    5. cd ~ sudo umount /mnt/msoffice (unmount)

Virtual Box Shared Folder:


1. sudo usermod -aG vboxsf $USER
2. sudo systemctl status vboxservice
	if disabled, 
	run: sudo systemctl enable --now vboxservice
3. ls -la /media (permission denied)
4. sudo chmod 755 /media
5. ls -la /media (again, it should work this time)
6. groups {
	 if vboxsf is not in the output:
		sudo usermod -aG vboxsf $USER
		exec su - $USER  (or just reboot)
	if vboxsf is in the output:
		cd /media/sf_E
		ls -la		(You can now access your shared folder directly)
7. now to access my shared folder in dolphin:
	a. In Dolphin's main location bar, navigate to /media.
	b. Right-click on the sf_E folder.
	c. Select Add to Places (or press Ctrl + B).
8. done
